# 💻 数字逻辑与开关理论 · 课堂笔记（Computer-Fundamentals-Notes）

基于 **单个独立 HTML 文件**（`index.html`）实现的交互式课堂笔记，无需任何外部依赖或服务器，**直接双击 `index.html` 即可在浏览器中打开使用**。

## 章节目录

- **第1章 开关理论基础**（1.1 二进制系统 ～ 1.6 数字集成电路）
- **第2章 组合逻辑**（2.1 组合逻辑分析 ～ 2.7 奇偶校验器）
- **第3章 时序逻辑**（3.1 锁存器 ～ 3.7 同步时序逻辑设计）

## 交互功能与界面特性

- **仿 GitHub 暗黑网页风格**（支持右上角切换深/浅主题）：宽屏全比例排版。
- **弹出式抽屉侧边栏**：点击左上角 `☰` 按钮从左侧弹出高亮目录树，背景自动虚化暗淡形成对比。
- **课堂互动组件**：
  - 实时进制转换器
  - 逻辑门交互模拟器（点击切换 `A`/`B` 电平）
  - 交互式 4 变量卡诺图
  - 悬停术语解释、例题折叠解析、选项卡、点击卡片、逐步演示
- **课后练习与学习进度**：支持单选题点击即判、填空题回车提交、即时显示答案与解析，并在 `Actions` 页统计各章学习进度。
